# Host routes

Generated by `npm run build:readme` from `docs/features.json` (`routes`) and the routes that `index.js` registers. Do not edit this file.

Every route is on dsh's authenticated `/api` channel. "Tether" tells whether the iPhone gateway forwards that method (`PLUS` in `tether/gateway/server.mjs`, as `/plus/<name>`). The gateway always refuses a body with `on` or `model`, so a phone never changes a switch or a model, also on a route that it can call.

| Route | Method | Request | Feature | Tether |
|---|---|---|---|---|
| `/api/composer-plus.continue` | POST | `{sessionId, afterSeq}`: continue the last stopped, failed or cut-off turn without a chat message. | continueButton | yes |
| `/api/composer-plus.changes` | GET | `?sessionId&mode=uncommitted\|unstaged\|staged\|branch`: the changed files of the chat's folder (read-only git) and the newest turn for Last Turn. | changesPanel | yes |
| `/api/composer-plus.diff` | GET | `?sessionId&mode&path`: the diff of one changed file. | changesPanel | yes |
| `/api/composer-plus.shot` | GET | `?id=<shot>`: one shipped Settings screenshot (`SHOTS` in index.js only). | Settings | no |
| `/api/composer-plus.update` | GET | No query: the latest GitHub release compared with this copy (`latest`, `newer`, `managed`, `url`, `notes`); calls GitHub and npm. `?current=1`: only the running version (What's new), no network call. | autoUpdate | no |
| `/api/composer-plus.grants` | GET | The saved grants, `{ [sessionId]: [tool] }`. | allowForChat | yes |
| `/api/composer-plus.grants` | POST | `{action: "grant", sessionId, tool}` or `{action: "revoke", sessionId}`. | allowForChat | yes |
| `/api/composer-plus.mobile` | GET | The switch and the gateway state. | mobileConnect | no |
| `/api/composer-plus.mobile` | POST | `{on}`: switch the gateway on or off (a switch route). | mobileConnect | no |
| `/api/composer-plus.queue-move` | POST | `{sessionId, itemId, to, before}`: move one queued message in dsh's queue. | queueReorder | yes |
| `/api/composer-plus.rollback` | GET | No query: the switch `{on}`. `?sessionId`: the withdrawn spans and whether dsh-rewind-plugin owns rollback. | turnRollback | yes |
| `/api/composer-plus.rollback` | POST | `{on}` (the switch), or `{sessionId, seq, preview?, files?}`: list or take back the turns from that message, with the files when `files` is true. | turnRollback | yes |
| `/api/composer-plus.delete-chat` | POST | `{sessionId}`: stop the chat and move its log folders, with its subagent chats, to the Trash. | deleteChat | yes |
| `/api/composer-plus.content-search` | GET | The switch `{on, active}`. | contentSearch | no |
| `/api/composer-plus.content-search` | POST | `{on}`: the switch (a switch route; applies after a dsh restart). | contentSearch | no |
| `/api/composer-plus.ideas` | POST | `{sessionId, locale?, focus?}`: suggest ideas (one model call), or `{sessionId, idea, plan?}`: start a chat for one idea. | featureIdeas | yes |
| `/api/composer-plus.idea-history` | GET | `?sessionId`: the earlier ideas of the chat's project. | featureIdeas | yes |
| `/api/composer-plus.idea-history` | POST | `{sessionId, remove}` or `{sessionId, clear: true}`: forget one or all. | featureIdeas | yes |
| `/api/composer-plus.later` | GET | `?sessionId`: the Later list of the chat's project. | featureIdeas | yes |
| `/api/composer-plus.later` | POST | `{sessionId, add \| remove \| start \| startAll, plan?}`: change the list or start chats for its ideas. | featureIdeas | yes |
| `/api/composer-plus.resume` | GET | The switch `{on}`. | resumeAfterRestart | no |
| `/api/composer-plus.resume` | POST | `{on}`: the switch (a switch route). | resumeAfterRestart | no |
| `/api/composer-plus.predict` | GET | The switch and the model; `?catalog=1` adds dsh's model list. | nextPrediction | no |
| `/api/composer-plus.predict` | POST | `{sessionId, afterSeq}`: the guess for that finished turn (one model call), or `{on}` / `{model}` (Settings only). | nextPrediction | yes |
| `/api/composer-plus.complete` | GET | The switch and the model; `?catalog=1` adds dsh's model list and the prediction's model. | typingCompletion | no |
| `/api/composer-plus.complete` | POST | `{sessionId, text}`: the rest of the typed message (one model call), or `{on}` / `{model}` (Settings only). | typingCompletion | yes |
| `/api/composer-plus.export` | GET | `?sessionId`: the chat's messages for the Markdown export (read-only, from the chat log). | exportMarkdown | no |

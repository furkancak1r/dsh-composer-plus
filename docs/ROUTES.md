# Host routes

Generated by `npm run build:readme` from `docs/features.json` (`routes`) and the routes that `index.js` registers. Do not edit this file.

Every route is on dsh's authenticated `/api` channel. "Tether" tells whether the iPhone gateway forwards that method (`PLUS` in `tether/gateway/server.mjs`, as `/plus/<name>`). The gateway always refuses a body with `on`, `model` or `ttlMs`, so a phone never changes a switch, a model or the grant time limit, also on a route that it can call.

| `/api/composer-plus.continue` | POST | `{sessionId, afterSeq}`: continue the last stopped, failed or cut-off turn without a chat message. | continueButton | yes |

| `/api/composer-plus.file-chats` | GET | `?sessionId&path` (`path` from the repository top): the chats of the same repository whose write/edit tools changed that file, one row per request, newest first (read from the chat logs only). | changesPanel | yes |

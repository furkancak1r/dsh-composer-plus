Fitur kenyamanan bergaya Codex untuk UI desktop dan web [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh): panel Perubahan, ide fitur dalam bentuk kartu geser, pencarian teks pesan di bilah samping, putar balik giliran beserta pemulihan file, penghapusan obrolan ke Tong Sampah, nama proyek di bawah kotak pesan, status proyek di bilah samping, riwayat input, pintasan mode rencana, Lanjutkan sekali klik, melanjutkan obrolan yang sedang berjalan setelah mulai ulang, seret dan lepas antrean, tautan sesi, ekspor obrolan sebagai Markdown, izin Tinjauan otomatis per obrolan, notifikasi latar belakang, akses dari iPhone dengan aplikasi Tether, dan pembaruan otomatis.

**Singkatnya:** satu plugin DeepSeek Harness (npm `dsh-composer-plus`, tampil sebagai **Composer Plus** di Pengaturan → Plugin) yang menambahkan panel Perubahan git, kartu ide fitur bergaya Tinder, pencarian bilah samping yang juga menemukan kata di dalam pesan, ↶ putar balik giliran (obrolan saja, atau obrolan dan file), Hapus obrolan, nama proyek di bawah kotak pesan, riwayat input ↑/↓, tombol alih `/plan` dengan Shift+Tab, ▶ Lanjutkan sekali klik, Lanjutkan setelah mulai ulang, pengurutan ulang antrean dengan seret dan lepas, Salin tautan sesi, Ekspor sebagai Markdown, “Izinkan untuk obrolan ini” untuk Tinjauan otomatis, notifikasi latar belakang, akses dari iPhone (Koneksi seluler, aplikasi Tether), 11 bahasa antarmuka tambahan, dan pembaruan otomatis.

<p align="center"><img src="docs/images/hero.webp" width="820" alt="DeepSeek Harness dengan Composer Plus: proyek yang sedang berjalan menampilkan spinner di bilah samping, dan panel Perubahan menampilkan diff git"></p>

Plugin komunitas tidak resmi. Pemeriksaan pembaruan melakukan panggilan jaringan (rilis GitHub dan registri npm). Nonaktifkan **Pembaruan otomatis** untuk menghentikannya saat dsh dimulai. **Paket skill bahasa Turki** (aktif secara default) mengunduh turkish-anti-ai-skill dari GitHub dan memeriksa versi baru sekali sehari, hanya saat **Bahasa aplikasi** adalah Türkçe; matikan di **Pengaturan → Composer Plus** untuk menghentikan panggilan ini. **Ide fitur** memanggil model obrolan Anda sendiri hanya saat Anda mengklik **Sarankan fitur**. **Prediksi pesan berikutnya** (aktif secara default) memanggil model yang dipilih di Pengaturan (model default dsh, kecuali Anda memilih yang lain) satu kali setelah setiap giliran selesai, tanpa klik. Nonaktifkan di **Pengaturan → Composer Plus** untuk menghentikan panggilan ini. **Lengkapi saat mengetik** (nonaktif secara default) memanggil model yang dipilih untuknya (secara default model prediksi) di setiap jeda saat Anda mengetik, setelah Anda mengaktifkannya. **Sempurnakan prompt** memanggil model hanya saat Anda mengklik tongkat ajaibnya. **Papan tugas** memanggil model obrolan baru satu kali untuk label setiap tugas yang Anda mulai di papan. Dengan pengaturan **Ringkasan AI** (default-nya **Cepat (tanpa AI)**), papan juga memanggil model obrolan yang sedang berjalan untuk catatan progres singkat saat Anda melihat progres tugas itu di papan atau di Tether. **Pemeriksaan tujuan** (aktif secara default) memanggil model satu kali setiap kali agen menandai `/goal` sebagai selesai dalam putaran otomatis. **Koneksi seluler** (nonaktif secara default) menerima koneksi iPhone dari jaringan lokal atau tailnet Anda hanya setelah Anda mengaktifkannya.

## Instalasi

**Aplikasi desktop:** Pengaturan → Plugin → **Tambahkan plugin** → masukkan `dsh-composer-plus` → **Aktifkan sekarang**.
Anda juga dapat menempelkan `https://github.com/furkancak1r/dsh-composer-plus` sebagai pengganti nama npm.

**Profil web / CLI:**

```sh
dsh plugin --profile web add dsh-composer-plus
```

Lalu mulai ulang dsh. (CLI tidak dapat memasang plugin ke profil desktop; profil itu dikelola oleh aplikasi.)

> pnpm milik dsh melewati versi yang berumur kurang dari 24 jam. Tepat setelah rilis, tambahkan versinya: `dsh-composer-plus@1.26.0`.

| **Panel perubahan** | <a id="feature-changespanel"></a>Bilah samping kanan → `+` → **Perubahan**. Halaman terbuka di **Pohon**: peta branch dari repositori obrolan. Geser ke kiri (atau **✕**, atau `←`) untuk melewatinya; **Urungkan** (atau `Z`) mengembalikan kartu yang dilewati. Klik **↓** (atau tekan `↓`) untuk menyimpan ide bagus untuk nanti. Untuk mendapatkan ide tentang satu area saja, ketik **Topik fokus** yang singkat di kolom di samping **Sarankan fitur** (paling banyak 80 karakter; `Enter` juga menyarankan), atau klik salah satu topik tetap di bawahnya: **Kinerja**, **Aksesibilitas**, **Pengujian**, **Keamanan**, **Kegunaan**, atau **Dokumentasi** (klik lagi untuk mengosongkannya). Model lalu hanya menyarankan fitur tentang topik itu; kolom kosong berarti fitur apa pun. Ide tidak disarankan dua kali dalam satu proyek: setiap ide yang disarankan (dilewati, disimpan, atau dimulai) masuk ke **Riwayat** proyek, model diminta untuk tidak menyarankannya lagi, dan judul yang berulang dibuang. **Riwayat** mencantumkannya dengan **Dimulai** atau **Disarankan**; **Lupakan** (atau **Lupakan semua**) membuat ide itu bisa muncul lagi; ide yang masih ada di daftar **Nanti** tidak masuk saran sampai Anda menghapusnya dari sana. ## Pengaturan

Setiap fitur dapat diaktifkan atau dinonaktifkan secara terpisah: dsh **Pengaturan → Composer Plus**. Setiap baris memiliki tangkapan layar kecil: arahkan penunjuk ke gambar itu untuk pratinjau yang lebih besar, atau klik untuk membukanya dalam ukuran penuh (`Esc` menutupnya). Kotak **Cari fitur** di bagian atas memfilter halaman menurut nama atau deskripsi (bahasa apa pun, tanpa membedakan huruf besar-kecil dan aksen); `Esc` mengosongkannya. Di sampingnya, **Semua**, **Aktif**, dan **Nonaktif** menampilkan semua fitur, hanya yang aktif, atau hanya yang nonaktif (matikan **Filter aktif/nonaktif** untuk menyembunyikannya). Setiap baris memiliki sakelar dan deskripsi singkat. **?** kecil setelah nama baris membuka bagian README ini yang menjelaskan fitur itu, di README bahasa antarmuka dsh. Perubahan langsung berlaku tanpa mulai ulang dan diingat di perangkat itu. Semua fitur aktif secara default, kecuali **Koneksi seluler**, **Lanjutkan setelah mulai ulang**, dan **Lengkapi saat mengetik**. Host dsh menyimpan sakelar ketiga fitur ini serta sakelar **Pencarian isi**, **Putar balik giliran**, **Prediksi pesan berikutnya**, dan **Pemeriksaan tujuan**, jadi sakelar itu berlaku untuk setiap jendela dan tetap ada setelah mulai ulang. Host juga menyimpan pilihan **Model** untuk **Prediksi pesan berikutnya**, untuk **Lengkapi saat mengetik** (bawaannya **Sama dengan prediksi pesan berikutnya**), untuk **Sempurnakan prompt**, untuk **Pemeriksaan tujuan** (keduanya bawaannya **Sama dengan model obrolan**), serta **Batas waktu** untuk **Izinkan untuk obrolan ini** (bawaannya 1 jam). **Pencarian isi** baru berubah setelah dsh dimulai ulang (dsh membacanya saat dimulai). Sampai saat itu, barisnya menampilkan **Mulai ulang dsh agar perubahan ini berlaku.**

## Privasi dan keamanan

- **Lanjutkan:** endpoint lokal yang terautentikasi hanya melanjutkan giliran terakhir yang terinterupsi, menolak permintaan yang usang atau duplikat, dan mempertahankan hook persetujuan yang ada. Endpoint ini tidak mengirim pesan pengguna baru.
- **Lanjutkan setelah mulai ulang:** nonaktif sampai Anda mengaktifkannya. Bagian Host hanya menyimpan ID obrolan dan waktu mulai di `$DSH_HOME/storages/dsh-composer-plus/resume.json` (izin akses hanya untuk pemilik), dan tidak ada yang keluar dari mesin Anda. Fitur ini melanjutkan obrolan hanya jika log dsh sendiri menyatakan bahwa dsh (bukan Anda) yang menghentikan giliran terakhirnya. Persetujuan dan Tinjauan otomatis berlaku untuk giliran yang dilanjutkan seperti biasa.

- **Panel perubahan:** git berjalan dalam mode hanya-baca di mesin Anda, di folder obrolan itu sendiri, melalui kanal `/api` dsh yang terautentikasi. Git tidak pernah melakukan commit, stage, atau fetch, dan hanya menampilkan jalur yang didaftarkan oleh git sendiri. Pohon mencantumkan hingga 1000 branch lokal dan remote serta menampilkan 300 commit terbaru dari satu branch: hanya garis induk pertamanya, jadi commit merge mewakili commit yang dibawanya. Pohon tidak pernah berpindah branch (checkout). **Obrolan ini** membaca log milik obrolan untuk menemukan file yang ditulis oleh alat file obrolan itu, lalu membandingkannya dengan snapshot Putar balik giliran milik obrolan di folder sementara yang langsung dihapus; fitur ini tidak menulis apa pun ke repositori Anda atau ke penyimpanan snapshot.
- **Ide fitur:** tidak ada yang berjalan sampai Anda mengklik **Sarankan fitur**. Setelah itu, bagian Host hanya membaca folder obrolan itu sendiri (browser tidak pernah mengirim jalur): nama entri tingkat atas, 6 kB pertama dari README, AGENTS.md, dan manifes (`package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, …), kerangka sisa README (judul bagian, baris tabel, butir daftar; paling banyak 6 kB), serta judul commit terbaru (`git log --format=%s`, paling banyak 6 kB), total paling banyak 28 kB. Bagian Host melewati `.env*`, file kunci, dan folder seperti `node_modules`. Bagian Host juga hanya membaca file biasa yang tetap berada di dalam folder: symlink yang menunjuk ke luar folder, FIFO, atau perangkat akan dilewati. Ringkasan ini dikirim ke model yang dipakai obrolan, melalui pengaturan penyedia bawaan dsh, sebagai satu permintaan; ringkasan ini tidak ditambahkan ke obrolan mana pun. Tidak ada yang ditulis ke proyek. Ide yang digeser ke kanan memulai obrolan baru dalam mode rencana, jadi persetujuan dan tinjauan rencana berlaku seperti biasa. **Buat sekarang** memulai obrolan tanpa mode rencana: model dapat langsung mengubah file, dengan persetujuan obrolan yang biasa dan Tinjauan otomatis. Ide yang disimpan untuk nanti (judul, ringkasan, alasan, upaya) disimpan bersama jalur folder proyek di `storages/dsh-composer-plus/later.json` di dalam dsh home (file hanya untuk pemilik); tidak ada yang masuk ke proyek. Riwayat ide yang disarankan (judul, ringkasan, alasan, upaya, tanggal, sudah dimulai atau belum) disimpan dengan cara yang sama di `storages/dsh-composer-plus/idea-history.json`, paling banyak 200 per proyek (yang terlama keluar lebih dulu); judul-judulnya dikirim ke model bersama **Sarankan fitur** berikutnya di proyek itu.
- **Pencarian isi:** tidak ada kode baru yang mencari di obrolan Anda. Plugin hanya mengaktifkan indeks pesan bawaan dsh (SQLite FTS5, `dsh-session-query-sqlite`) dan memberinya sebuah file, `$DSH_HOME/cache/composer-plus/session-search.db` (file dan folder hanya untuk pemilik). File ini berisi teks pesan pengguna dan asisten Anda, jadi sama privatnya dengan log obrolan di `$DSH_HOME/sessions`. Tidak ada yang keluar dari mesin Anda. File ini adalah salinan yang dapat dibuat ulang oleh dsh: Anda dapat menghapusnya saat dsh ditutup. Sakelarnya ada di `$DSH_HOME/storages/dsh-composer-plus/content-search.json`.
- **Putar balik giliran:** sebelum setiap pesan Anda, Host mengambil snapshot git dari folder obrolan ke penyimpanannya sendiri, `$DSH_HOME/cache/composer-plus/rollback/<chat>.git` (folder hanya untuk pemilik). Penyimpanan ini berisi salinan file di folder itu yang terlihat oleh git (bukan file yang diabaikan), jadi sama privatnya dengan proyek. Fitur ini membaca objek repositori Anda (tanpa menyalin apa yang sudah dimiliki git) dan tidak pernah menulis index, `HEAD`, branch, tag, stash, atau config repositori Anda. Satu-satunya perubahan yang dibuat git di sana adalah stempel waktu yang lebih baru pada file objek yang dipakai ulang (ini menunda pembersihannya oleh `git gc`). Putar balik dengan file hanya menulis file biasa di dalam folder obrolan; symlink, pipe, dan apa pun di luar folder dilewati. Tidak ada yang keluar dari mesin Anda. Anda dapat menghapus penyimpanan ini saat dsh ditutup (putar balik lalu hanya berlaku untuk obrolan, sampai ada pesan baru). **Hapus obrolan** juga menghapus penyimpanan milik obrolan itu. Sakelarnya ada di `$DSH_HOME/storages/dsh-composer-plus/rollback.json`. Putar balik dengan file juga menyimpan file seperti keadaannya tepat sebelum putar balik (`refs/r/…` di penyimpanan yang sama), untuk **Ulangi**; putar balik yang sudah diulangi dicatat di `$DSH_HOME/storages/dsh-composer-plus/redone.json` (hanya untuk pemilik).
- **Buka isu GitHub** (Ide fitur → daftar **Nanti**): hanya berjalan saat Anda mengkliknya. Bagian Host menjalankan GitHub CLI milik Anda sendiri (`gh issue create`) di folder obrolan, dengan judul dan ringkasan ide yang tersimpan (serta alasan ide itu penting); `gh` memakai login-nya sendiri dan remote GitHub folder itu, jadi isu dibuat di repositori tersebut dengan akun Anda, dan GitHub menampilkannya kepada semua orang yang dapat melihat repositori itu. dsh menghapus variabel yang namanya mirip token dari perintah yang dijalankannya; jika Anda memberi `gh` token melalui `GH_TOKEN` atau `GITHUB_TOKEN`, plugin hanya meneruskan variabel itu ke `gh`. Tautan isu disimpan bersama ide di `later.json`.
- **Laporkan isu** (Pengaturan → Composer Plus → **Laporkan isu…**, atau menu **…** obrolan → **Laporkan isu Composer Plus…**): tidak ada yang berjalan sampai Anda mengklik. **Tulis draf** hanya mengirim jenis dan teks yang Anda ketik (bukan obrolan, bukan proyek) ke model default dsh, dalam satu panggilan. Bagian Host menambahkan satu baris berisi versi Composer Plus, dsh, dan sistem operasi, serta mengganti jalur folder home Anda dengan `~`. **Buka isu** menjalankan GitHub CLI milik Anda sendiri (`gh issue create --repo furkancak1r/dsh-composer-plus`) dengan login `gh` Anda, jadi isu ini publik dan menampilkan akun GitHub Anda. Teks yang tampak seperti kunci, token, atau kata sandi ditolak dan tidak keluar dari Mac Anda.
- **Obrolan yang mengubah file ini** (Perubahan, menu "…" sebuah file): bagian Host membaca log obrolan yang foldernya ada di repositori yang sama, sebagaimana dsh menyimpannya, lalu mengembalikan judul setiap obrolan, waktunya, dan baris pertama permintaannya; bagian Host tidak pernah membuka file itu sendiri.
- **Branch Git di baris obrolan:** bagian Host menjalankan `git branch --show-current` (hanya baca) di folder obrolan saat giliran dimulai dan saat berakhir, dan hanya menyimpan ID obrolan, nama branch, dan waktunya di `$DSH_HOME/storages/dsh-composer-plus/session-branches.json` (file hanya untuk pemilik, 2000 obrolan terbaru). Sakelarnya ada di `branches.json` di sebelahnya.
- **Cari di obrolan** hanya berjalan di halaman: fitur ini membaca teks yang ditampilkan halaman dan tidak mengirim apa pun.
- **Ekspor obrolan sebagai Markdown:** bagian Host hanya membaca log milik obrolan itu (pesan yang sama dengan yang ditampilkan dsh) dan memberikannya ke halaman; bagian ini tidak membaca file proyek dan tidak mengirim apa pun lewat jaringan. Markdown hanya masuk ke papan klip Anda atau ke file yang Anda simpan.
- **Hapus obrolan:** memindahkan folder log milik obrolan (`$DSH_HOME/sessions/<project>/<chat>`) ke Tong Sampah. Folder proyek tidak disentuh.
- **Izinkan untuk obrolan ini:** izin disimpan beserta waktu pemberiannya di `$DSH_HOME/storages/dsh-composer-plus/chat-grants.json` (izin akses hanya untuk pemilik). Satu izin berlaku untuk satu alat tertentu di satu obrolan, sampai batas waktu berakhir (1 jam secara default). Jika alat itu dapat menulis, izin itu juga mencakup penulisan apa pun. Cabut izin dari chip di header.
- Tinjauan otomatis tetap berjalan pada setiap panggilan; tinjauan yang gagal tidak pernah diizinkan secara otomatis.
- **Koneksi seluler:** nonaktif sampai Anda mengaktifkannya. Selama aktif, bagian Host menjalankan gateway Tether: HTTPS di port 19390 yang hanya menerima subnet Wi-Fi dan tailnet Anda (100.64.0.0/10), serta halaman pemasangan di `127.0.0.1:19391` (hanya Mac ini). Ponsel memerlukan kode sekali pakai dari kode QR (berlaku 5 menit) dan klik **Approve** dari Anda di Mac. Ponsel menyematkan (pin) sertifikat gateway. Mac hanya menyimpan hash token setiap ponsel (30 hari, diperpanjang selama dipakai); **Remove** langsung menutup koneksi ponsel itu. Ponsel hanya dapat memanggil daftar metode dsh yang diizinkan (obrolan, prompt, lampiran, perintah garis miring, persetujuan, pertanyaan, model, agen, tujuan), bukan pengaturan, kredensial, browser file, atau terminal. "Tailscale only" menolak setiap koneksi dari jaringan lokal, termasuk koneksi yang sudah terbuka. Log akses menyimpan 200 percobaan koneksi terbaru (waktu, alamat IP, nama perangkat, diizinkan atau ditolak, dan alasannya) di `access.json`; log ini tidak pernah menyimpan token atau kode pemasangan. Data: `$DSH_HOME/storages/dsh-composer-plus/mobile/` (file hanya untuk pemilik). Detail: [tether/README.md](tether/README.md).
- **Komputer jarak jauh:** nonaktif sampai Anda mengaktifkannya di setiap Mac. **Izinkan komputer lain membuka Mac ini** membuka port HTTPS kedua (19392) hanya di alamat Tailscale Mac ini (tidak di Wi-Fi, dan tidak diumumkan dengan Bonjour). Mac lain memerlukan tautan pemasangan sekali pakai (berlaku 5 menit), sertifikat yang cocok (disematkan), dan klik **Setujui** dari Anda. Mac ini hanya menyimpan hash token Mac itu. Komputer yang dipasangkan mendapat kendali penuh atas dsh di Mac ini, seolah-olah Anda memakainya di sini: obrolan, model, alat, file, dan terminalnya. Hapus komputer itu di panel Pengaturan, dan koneksinya langsung ditutup. ## Pemecahan masalah

- **Tidak ada notifikasi di macOS:** Pengaturan Sistem → Pemberitahuan → DeepSeek Harness → izinkan. Pilih Peringatan agar notifikasi tetap tampil di layar.
- **▶, pegangan antrean, status proyek, opsi proyek terbaru, Ciutkan semua proyek, Salin jalur, kotak pencarian proyek, prediksi pesan berikutnya, pelengkapan saat mengetik, Izinkan untuk obrolan ini, atau klik kanan hilang setelah dsh diperbarui:** elemen-elemen ini menempel ke HTML dsh saat ini karena dsh belum memiliki slot untuknya. Jika dsh mengubah markup itu, elemen-elemen ini menyembunyikan dirinya sendiri; tidak ada hal lain yang rusak. Silakan buka [issue](https://github.com/furkancak1r/dsh-composer-plus/issues).
- **"Pembaruan gagal" atau "tidak dipasang dari npm":** salinan yang ditautkan dari folder lokal atau yang diganti namanya tidak dapat memperbarui dirinya sendiri; pasang ulang `dsh-composer-plus` dari Pengaturan → Plugin. Selain itu, pesan menampilkan baris pertama error pnpm; **Periksa pembaruan** mencoba lagi.
- **Koneksi seluler menyatakan gateway tidak berjalan:** "no IPv4 address on en0" berarti Mac ini tidak memiliki alamat Wi-Fi/Ethernet; "EADDRINUSE" berarti dsh lain (atau aplikasi lain) memakai port 19390 atau 19391. Hanya satu dsh yang dapat menjalankan Koneksi seluler pada satu waktu.
- **Koneksi seluler, Lanjutkan setelah mulai ulang, atau Pencarian isi menampilkan "Mulai ulang dsh":** plugin diperbarui saat dsh sedang berjalan (atau, untuk Pencarian isi, Anda mengubah sakelarnya); status baru dimuat setelah mulai ulang.
- **Pencarian hanya menemukan judul:** Pencarian isi nonaktif, dsh belum dimulai ulang sejak Anda mengaktifkannya atau memasang plugin, atau kata itu hanya ada di output alat (lihat Batasan).
- **Tidak ada tombol ↶ di pesan saya:** Putar balik giliran nonaktif, obrolan itu adalah obrolan subagen, atau dsh-rewind-plugin terpasang (gunakan tombol ↶ miliknya). Setelah pembaruan, mulai ulang dsh.
- **Obrolan dan file berwarna abu-abu:** proyek bukan repositori git, tidak ada snapshot dari sebelum pesan itu (pesan lebih lama dari plugin, atau salah satu dari 50 snapshot terbaru telah menggantikannya), atau tidak ada file yang berubah.
- **Hapus menyatakan dsh lain sedang membuka obrolan ini:** dsh kedua pada dsh home yang sama memegang kunci obrolan. Tutup jendela atau dsh itu, lalu hapus lagi. Sementara itu, obrolan tetap diarsipkan.
- **iPhone saya tidak dapat terhubung setelah saya mengaktifkan "Tailscale only":** Tailscale harus aktif di Mac dan di iPhone. Panel Koneksi seluler memberi peringatan saat Tailscale nonaktif di Mac. Log akses menampilkan setiap percobaan yang ditolak beserta alasannya.
- **Obrolan tidak berlanjut setelah mulai ulang:** Lanjutkan setelah mulai ulang nonaktif saat dsh ditutup, Anda sendiri yang menghentikan giliran itu, giliran sudah berakhir (selesai atau gagal), obrolan diarsipkan, atau lebih dari 20 obrolan sedang berjalan (20 yang terbaru berlanjut).
- **Antrean kosong setelah mulai ulang:** dsh sendiri mengosongkan antrean saat ditutup. Lanjutkan setelah mulai ulang hanya mengembalikannya di obrolan yang dilanjutkan; di obrolan lain, kirim lagi pesannya. Pesan yang Anda hapus tepat sebelum dsh ditutup bisa kembali: hapus lagi.
- **Buka isu GitHub menampilkan "gh could not open the issue":** pesan itu adalah baris pertama dari `gh` sendiri. Jalankan `gh auth status` di terminal dan login dengan `gh auth login`; folder obrolan harus memiliki remote GitHub (`git remote -v`). "not installed or not on the PATH of dsh" berarti dsh tidak menemukan `gh`: pasang alat itu, atau mulai dsh dari terminal tempat `gh` berfungsi.
- **Laporkan isu menampilkan "gh could not open the issue":** pesan itu adalah baris pertama dari `gh` sendiri. Jalankan `gh auth status` di terminal dan login dengan `gh auth login`. Atau klik **Buka di GitHub sebagai gantinya**: halaman isu baru milik GitHub sendiri terbuka dengan draf yang sudah terisi, dan Anda mengirimkannya di sana.
- **Tidak ada label branch di baris obrolan:** bilah samping tidak dalam tampilan “Dalam satu daftar” (dalam “Ruang Kerja” dan “Pohon Ruang Kerja”, tidak ada baris obrolan yang menampilkan label), obrolan itu belum memiliki giliran sejak Anda memasang versi ini, foldernya bukan repositori git, atau **Branch Git di baris obrolan** nonaktif. Setelah pembaruan, mulai ulang dsh (bagian Host mencatat branch).
- **Pemeriksaan tujuan menyebut pengujian keluar dengan kode 127 atau "not found":** dsh yang dimulai dari Finder atau Dock dapat memiliki PATH yang lebih pendek daripada terminal Anda, sehingga tidak menemukan `npm`, `pnpm`, atau `cargo`. Mulai dsh dari terminal, atau atur perintah pengujian Anda sendiri dengan jalur lengkap di **Pemeriksaan tujuan** → **Edit**. **Jalankan sekarang** langsung menampilkan hasilnya.
- **Tujuan tidak ditutup dan agen terus bekerja:** **Pemeriksaan tujuan** menemukan pengujian yang gagal atau pekerjaan yang belum selesai; baris di bawah tujuan menampilkan alasannya (arahkan penunjuk ke hasil untuk melihat detailnya). Perbaiki penyebabnya atau perintah pengujiannya, atau selesaikan tujuan sendiri dengan `/goal` atau bilah tujuan (penyelesaian itu tidak diperiksa).
- **Pemasangan gagal tepat setelah rilis:** tambahkan versinya (`dsh-composer-plus@1.26.0`), lihat catatan pemasangan di atas.
- **Cadangkan sekarang menyatakan "Tindakan pencadangan lain sedang berjalan":** ada tindakan yang berjalan di jendela dsh lain atau di konsol penyelamat (keduanya berbagi file kunci, `.composer-plus.lock`, di folder cadangan). Tunggu sampai tindakan itu selesai. Jika tidak ada tindakan yang berjalan, kunci milik proses yang sudah ditutup diambil alih pada klik berikutnya.
- **Konsol penyelamat menyatakan "dsh is running":** keluar dari dsh terlebih dahulu. Jika dsh memang sudah tertutup, file yang disebut dalam pesan itu tersisa dari crash: hapus file itu dan coba lagi.
- **Setelah pemulihan, dsh tidak mau dimulai atau ada plugin yang hilang:** paket plugin sebuah profil harus dipasang lagi. Konsol penyelamat menawarkannya setelah pemulihan; atau jalankan `pnpm install` di setiap folder di bawah `$DSH_HOME/profiles/` yang dicantumkannya. Rahasia yang tidak ada di vault (komputer lain) harus dimasukkan lagi: konsol mencantumkannya.

## Batasan

- Lanjutkan tanpa pesan bergantung pada siklus hidup `agent/pre-step` → `agent/request` dsh. Periksa ulang kompatibilitas saat meningkatkan versi dsh.
- **Ide fitur** menyimpan kartu di memori untuk setiap obrolan sampai dsh atau halaman dimuat ulang; setelah itu **Sarankan fitur** bertanya lagi ke model. Kartu muncul dalam bahasa UI yang dipakai dsh saat Anda mengklik. Setelah Anda mengganti bahasa, kartu yang sudah ada di tumpukan tetap memakai bahasanya, dan **Ide lainnya** memakai bahasa yang baru. Model hanya melihat ringkasan proyek yang singkat, bukan kodenya, jadi sebuah ide bisa saja mengulang sesuatu yang sudah ada di proyek: lewati saja. Obrolan baru berjalan dalam mode rencana hanya jika profil memiliki perintah `/plan` dsh; jika tidak, ide dikirim sebagai pesan pertama biasa. Daftar **Nanti** terikat pada jalur folder obrolan: folder yang sama yang dibuka melalui symlink memiliki daftar sendiri. Daftar ini menyimpan paling banyak 50 ide per proyek (hapus satu untuk menambah lagi) dan menyimpan judul yang sama hanya sekali. Menyeret kartu hanya memutuskan kiri atau kanan; gunakan **↓** untuk menyimpannya dan **▶** untuk langsung membuatnya. Pengulangan hanya dikenali dari judulnya: model masih bisa menyarankan ide lama dengan nama baru; lewati saja. Jika model hanya menjawab dengan ide lama, tidak ada yang baru yang muncul: klik lagi. Topik fokus yang sempit membuat hal ini lebih mungkin terjadi; gunakan topik yang lebih luas atau kosongkan topiknya. Topik fokus tetap ada di kolom untuk setiap obrolan sampai dsh atau halaman dimuat ulang.
- **Ekspor obrolan sebagai Markdown** hanya berisi pesan Anda sendiri dan balasan teks asisten: panggilan alat beserta outputnya, proses berpikir, gambar (ditandai dengan baris `[image]`), konteks tersembunyi, dan pesan yang dikeluarkan oleh Putar balik giliran atau dsh-rewind-plugin tidak disertakan. Balasan dalam satu giliran digabung menjadi satu bagian. Satu ekspor berisi paling banyak sekitar 4 juta karakter; obrolan yang lebih panjang hanya diekspor bagian pertamanya, dengan sebuah catatan.
- **Lanjutkan setelah mulai ulang** melanjutkan giliran; fitur ini tidak memutar ulang giliran itu. Panggilan alat yang sedang berjalan saat dsh ditutup berakhir dengan hasil “outcome unknown” (hasil tidak diketahui) dari dsh. Model diberi tahu agar tidak mengulang pekerjaan yang sudah selesai, tetapi perintah yang tidak aman dijalankan dua kali tetap bisa berjalan lagi. Subagen, persetujuan, dan pertanyaan yang masih terbuka tidak dipulihkan: obrolan induknya berlanjut dan bertanya lagi. Paling banyak 20 obrolan berlanjut setiap kali dsh dimulai.
- **Lanjutkan setelah mulai ulang** dan antrean: dsh mengosongkan antrean obrolan saat ditutup. Plugin mengembalikan pesan antrean Anda dari log obrolan, dengan urutan, suntingan, gambar, dan file-nya; pesan itu berjalan setelah giliran yang dilanjutkan. Hanya obrolan yang dilanjutkan yang mendapatkan antreannya kembali (sakelar aktif, ditutup saat giliran berjalan). dsh mencatat penghapusan pesan antrean terakhir oleh Anda dengan cara yang sama: jika Anda menghapusnya dan dsh ditutup sebelum langkah berikutnya dimulai, pesan itu kembali.

- **Pencarian isi** adalah pencarian bawaan dsh, jadi batasannya sama dengan batasan dsh. Pencarian ini hanya mencakup pesan pengguna dan asisten: bukan output alat (perintah, isi file, hasil), bukan penalaran, dan tidak ada filter untuk pesan pengguna, asisten, atau alat. Pencarian mencocokkan kata utuh, bukan bagian kata (`deploy` tidak menemukan `deployment`); huruf beraksen cocok dengan huruf tanpa aksen (`seker` menemukan `şeker`). Satu baris per obrolan, dengan cuplikan 240 karakter dari dsh, paling banyak 20 baris.
- Biaya **Pencarian isi**, diukur pada salinan 247 log obrolan nyata (159 MB, dsh 0.2.1-rc.2, Apple Silicon, 32 GB): pencarian pertama setelah dsh dimulai membangun indeks dalam sekitar 15 detik. Selama waktu itu, Host dsh tidak menjawab apa pun selama sekitar 7 detik, jadi obrolan lain berhenti melakukan streaming sesaat (halamannya sendiri tidak membeku). Memori Host bertambah sekitar 1,1 GB pada puncaknya; satu menit kemudian, memori masih sekitar 0,5–0,6 GB di atas awal, sampai dsh ditutup. File indeks berukuran sekitar 165 MB. Pencarian berikutnya memakan waktu sekitar 0,5 detik. Setelah mulai ulang, pencarian pertama memakan waktu sekitar 1 detik (hanya obrolan baru atau yang berubah yang ditambahkan) dan menambah sekitar 70 MB. Nonaktifkan fitur ini jika memori komputer Anda kecil.
- **Pencarian isi** baru berlaku setelah dsh dimulai ulang, dan file indeks dipakai bersama oleh setiap dsh yang memakai dsh home yang sama: jalankan hanya satu dsh seperti itu pada satu waktu (dsh hanya mengizinkan satu pemilik per file indeks).
- **Putar balik giliran** mengembalikan file hanya di repositori git, dan hanya di folder obrolan. Fitur ini menyimpan 50 snapshot terbaru per obrolan. File yang diabaikan (`.gitignore`, `info/exclude`, file ignore global Anda), folder kosong, symlink, dan submodule tidak dikembalikan. File yang diabaikan saat snapshot diambil tidak pernah dihapus, bahkan jika giliran itu mengubah aturan ignore. File yang tidak dapat dibaca git tidak dimasukkan ke snapshot. Setiap pesan Anda menjalankan satu `git add --all` dari folder obrolan ke penyimpanan pribadi. Di folder yang sangat besar dengan banyak file yang tidak dilacak, ini bisa memakan waktu beberapa detik, dan panggilan alat berikutnya menunggunya (paling lama 10 detik; setelah itu snapshot selesai di latar belakang). Jika `git gc` repositori Anda menghapus objek yang diperlukan snapshot lama, file itu dicantumkan sebagai tidak dikembalikan. Hanya teks pesan yang kembali ke kotak pesan: tambahkan lagi gambar atau filenya. Obrolan subagen tidak memiliki ↶ (perubahan file oleh subagen dihitung sebagai perubahan obrolan yang memulainya). Obrolan yang diekspor (`/export`) masih berisi pesan yang ditarik. Ide satu penanda tersembunyi yang menarik sebagian obrolan berasal dari [dsh-rewind-plugin](https://github.com/SiriLee/dsh-rewind) karya SiriLee (MIT); Composer Plus tidak memakai kode darinya.
- **Hapus obrolan** memerlukan fitur arsip dsh (dsh 0.2.0 dan yang lebih baru). Obrolan (atau salah satu obrolan subagennya) yang tidak berhenti dalam 15 detik, atau yang dipegang oleh dsh lain, tetap diarsipkan dan tidak ada yang dipindahkan. Di sistem selain macOS, folder sampah harus berada di disk yang sama dengan riwayat obrolan. Obrolan terbuka yang Anda hapus tetap ada di memori dsh, dalam keadaan diarsipkan dan tersembunyi, sampai dsh dimulai ulang. Kosongkan Tong Sampah sendiri; dsh tidak melakukannya.
- Antrean dsh tidak memiliki tindakan `move`, jadi bagian Host plugin memindahkan pesan antrean itu sendiri di dalam antrean dsh (satu perubahan, pesan yang sama). Pesan dengan gambar atau file juga dapat dipindahkan. Hanya pesan Anda sendiri yang dapat dipindahkan: putaran tujuan atau balasan pertanyaan di antrean tetap di tempatnya. Jika sebuah pesan mulai dikirim saat Anda menyeret, tidak ada yang dipindahkan dan muncul pemberitahuan tentang hal itu.
- dsh 0.2.1 langsung memuat pembaruan jika versi baru tidak mengubah pengaturan dsh apa pun; dalam kasus lain, dan pada dsh 0.2.0, mulai ulang dsh untuk memuatnya. Plugin tidak pernah memulai ulang dsh untuk Anda. Profil web/CLI tanpa pengelola plugin dsh hanya melaporkan adanya versi baru.
- **Yang baru di Composer Plus N** menampilkan catatan dalam bahasa **Bahasa aplikasi**. Bahasa antarmuka dengan wilayah lain mendapat catatan bahasa dasarnya (`en-GB` mendapat catatan bahasa Inggris, `zh-TW` catatan bahasa Tionghoa dari `zh`). Bahasa tanpa catatan (bahasa yang ditambahkan paket bahasa lain, atau `pt-PT`, yang bukan `pt-BR`) menampilkan catatan bahasa Inggris. Catatan ikut bersama versi baru. Jika salinan yang berjalan tidak memiliki berkas catatan yang dapat dibaca (`release-notes.json`), jendela menampilkan catatan bahasa Inggris dari GitHub.
- Versi yang terpasang saat dsh berjalan (pembaruan lewat Pengaturan → Plugin atau folder yang disalin) baru dimuat setelah dsh dimulai ulang: sampai saat itu, **Pembaruan Composer Plus** menampilkan versi yang berjalan dan meminta mulai ulang. Jendela **Yang baru di Composer Plus N** versi itu muncul sekali pada awal pertama versi tersebut. Awal pertama setelah plugin ini dipasang tidak menampilkan jendela; **Yang baru di versi ini** membuka catatan versi yang berjalan.
- Baris bintang GitHub di bawah catatan tidak dapat mengetahui apakah Anda sudah memberi bintang pada repositori: plugin tidak membuat panggilan jaringan untuk itu. Setiap browser (dan aplikasi desktop) menyimpan catatannya sendiri, jadi baris itu bisa muncul sekali lagi di browser lain.
- **Tolak dengan catatan** mengirim catatan sebagai pesan ke giliran yang menunggu, lalu menolak permintaan; dsh menampilkan catatan itu di obrolan sebagai pesan Anda. Selama kolom catatan terbuka, kartu hanya menampilkan **Batal** dan **Tolak**, jadi satu klik tidak dapat mengizinkan permintaan secara tidak sengaja; `Esc` atau **Batal** mengembalikan tombol-tombol dsh. Catatan kosong tidak mengirim apa pun (gunakan **Tolak** milik dsh sendiri). Jika penolakan gagal setelah catatan terkirim (misalnya, permintaan itu sementara itu sudah dijawab di tempat lain), catatan tetap ada di obrolan dan model membacanya di langkah berikutnya. Tombol ini masuk ke markup kartu persetujuan dsh (`data-approval-key`), karena dsh tidak punya slot untuk tindakan kartu; jika pembaruan dsh mengubah markup itu, tombol tidak tampil dan **Tolak** milik dsh sendiri tetap berfungsi seperti sebelumnya. Satu catatan paling banyak berisi 4.000 karakter.
- **Input rahasia** hanya menyembunyikan teks persis dari sebuah nilai: `[secret]` menggantikannya di hasil alat berikutnya dalam obrolan yang sama. Agen tetap dapat membaca file dengan perintah shell dan mencetak nilai dalam bentuk lain (base64, sebagian, dengan spasi), dan bentuk itu sampai ke model. Alat file milik agen (read, grep, write, edit) tidak dapat membuka folder rahasia. Jika nilai itu juga kata yang umum, hasil lain dalam obrolan itu juga menampilkan `[secret]`. File tetap ada sampai giliran berakhir; jika dsh tertutup selama giliran, start berikutnya menghapusnya. Satu obrolan hanya dapat punya satu permintaan terbuka pada satu waktu. Alat ini menambahkan sekitar 870 karakter (sekitar 220 token, perkiraan) ke setiap permintaan model: nonaktifkan jika tidak dipakai.
- **Kutip dalam balasan** mengutip teks seperti yang ditampilkan halaman: blok kode, tabel, atau daftar menjadi baris biasa tanpa tanda Markdown. Pilihan yang mulai di satu jawaban dan berakhir di jawaban lain, atau yang menyentuh proses berpikir, baris alat, atau pesan Anda sendiri, tidak menampilkan tombol: pilih di dalam satu jawaban saja. Tombol menemukan jawaban lewat struktur obrolan dsh, karena dsh tidak punya slot untuk pilihan teks; jika pembaruan dsh mengubah struktur itu, tombol tidak muncul. Jika kutipan berada di akhir kolom, satu baris kosong lagi ditambahkan agar baris berikutnya yang Anda ketik mulai di bawahnya; dsh menghapus baris kosong di akhir saat mengirim.
- **Kutip dari pratinjau file** membaca pratinjau file milik dsh sendiri: nomor baris berasal dari baris-baris pratinjau itu, jadi nomornya tepat untuk file kode dan teks. File Markdown tampil sebagai halaman berformat, jadi kutipannya berisi teks tanpa tanda Markdown dan tanpa nomor baris; kutipan PDF berisi halaman, bukan baris. Pilihan di header path, di penampil lain (spreadsheet, file Office, gambar), atau yang melintasi dua file terbuka tidak menampilkan tombol, begitu juga bilah samping kanan dalam layar penuh (saat itu kolom ketik tidak ada di layar). Tombol menemukan pratinjau lewat markup dsh, karena dsh tidak punya slot untuk pilihan di sana; jika pembaruan dsh mengubah markup itu, tombol tidak muncul. Hanya teks yang dipilih yang masuk ke kolom ketik: jika file berubah kemudian, kutipan tidak berubah.
- **Obrolan samping** hanya baca berkat mode hanya baca milik dsh sendiri: alat file tidak dapat menulis, dan perintah shell berjalan di sandbox dsh tanpa izin tulis (atau tidak berjalan saat sandbox tidak dapat dimulai). Agen tetap dapat meminta akses lebih dengan kartu persetujuan dsh, dan panggilan jaringan (misalnya permintaan API) tetap dapat mengubah sesuatu di luar komputer. Salinan dibuat pada saat terbaru ketika tidak ada pesan yang menunggu di antrean, jadi pertanyaan yang diajukan saat pesan masih menunggu tidak melihat apa yang terjadi setelahnya. Langkah obrolan yang sedang berjalan ditutup di salinan, jadi obrolan samping tahu awal langkah itu, tetapi tidak tahu hasilnya. Obrolan samping adalah obrolan biasa: tetap di bilah samping dan dihitung dalam pemakaian model Anda; arsipkan di sana. Bawa kembali hanya mengambil pesan milik obrolan samping (paling banyak 12.000 karakter) dan hanya balasan terakhir dari setiap pertanyaan; catatan agen di antara panggilan alatnya tidak ikut. dsh tidak menyediakan slot bagi plugin untuk menampilkan obrolan di bilah samping kanan, jadi obrolan samping terbuka di tampilan utama.
- **Catatan diff** hanya bekerja di panel perubahan, tidak di tampilan Giliran terakhir milik dsh. Rentang harus tetap dalam satu blok diff (satu bagian `@@`). Catatan disimpan di penyimpanan browser ini, jadi browser lain atau dsh di komputer lain tidak melihatnya; Tether menyimpan catatannya sendiri di memori. Catatan menyimpan baris seperti saat Anda mengklik: jika agen mengubah file kemudian, catatan tetap menampilkan baris dan nomor lama. Paling banyak 50 catatan per obrolan, 2.000 karakter per catatan, dan 40 baris per catatan (lalu baris `…`).
- **Izinkan untuk obrolan ini** menghitung batas waktu sejak izin diberikan. Batas waktu baru langsung berlaku untuk izin yang sedang berjalan, jadi batas yang lebih pendek dapat langsung mengakhirinya. Izin dari versi 1.12 dan sebelumnya tidak memiliki waktu: setelah pembaruan, agen bertanya sekali lagi untuk alat-alat itu.
- **Pertahankan fokus composer** mengembalikan fokus hanya setelah perintah `/` atau skill. Saat dsh memproses perintah, kotak pesan tetap hanya-baca selama beberapa milidetik, jadi tombol yang ditekan dalam waktu itu hilang. Jika menu `/` dsh masih terbuka, `Enter` memilih baris yang disorot dan tidak mengirim.
- **Sesuaikan kartu pertanyaan dengan jendela** hanya mengubah kartu pertanyaan dsh, bukan kartu tinjauan rencana. Fitur ini menemukan kartu melalui markup dsh (`data-question-key`, `data-question-scroll`); jika pembaruan dsh mengubah markup itu, kartu tampil seperti yang digambar dsh. Tinggi kartu mengikuti jendela, bukan chat: di chat dalam panel samping yang sempit, kartu yang tinggi masih dapat melewati bagian atas chat.
- **Sesuaikan header chat dengan jendela** menemukan header chat dsh dari nama kelas yang dibuat dsh (`_titleRow`, `_titleCluster`, `_crumbs`, `_headerActions`, `_headerUtilities`), karena dsh tidak menyediakan kait tata letak untuknya. Jika pembaruan dsh mengganti nama itu, header tampil seperti yang digambar dsh. Di kolom chat yang sangat sempit header bisa memakai dua atau tiga baris, sehingga ruang di atas pesan menjadi lebih kecil.
- **Subagen yang berjalan di header chat** hanya mengubah teks penghitung milik dsh. Fitur ini menghitung subagen langsung dari chat (jumlah yang sama dengan dsh), bukan subagen dari subagen. dsh menggambar daftar yang terbuka tanpa tempat untuk plugin, jadi baris total ditempatkan di atas struktur daftar dsh (`role="tree"`). Jika pembaruan dsh mengubah struktur itu, daftar tidak punya baris total dan header tetap menunjukkan jumlah yang berjalan.
- **Koneksi seluler** hanya berfungsi di macOS (memakai `en0`, `openssl`, `swift`, dan `dns-sd`). Fitur ini memakai port tetap 19390 dan 19391, jadi hanya satu dsh di setiap Mac yang dapat menjalankannya pada satu waktu (setiap Mac adalah satu entri dalam daftar Mac di ponsel). Dengan kunci APNs di `apns.json` (lihat `tether/README.md`), Mac mengirim notifikasi lewat layanan push Apple, jadi notifikasi tetap datang saat Tether tertutup; Mac harus menyala dengan dsh terbuka. Tanpa kunci itu, ponsel hanya mendapat notifikasi saat Tether terbuka atau baru saja masuk ke latar belakang. Tether hanya mengirimnya setelah Anda mengaktifkan "Settings → Notifications → Send notifications" di Tether. Tether menyimpan opsi ini dan jam-jamnya secara terpisah untuk setiap Mac yang dipasangkan. Opsi ini nonaktif secara default di setiap Mac, dan iOS meminta izin saat Anda mengaktifkannya. Aplikasi iOS belum ada di App Store: bangun aplikasi itu dari `tether/ios` dengan Xcode. "Tailscale only" tetap memerlukan alamat Wi-Fi atau Ethernet di Mac (gateway hanya mulai jika ada alamat itu). Log akses terpisah untuk setiap Mac dan hanya menyimpan 200 percobaan terbaru; percobaan yang berulang dalam satu menit menambah hitungan satu pada baris yang sama. Kunci aplikasi Setiap notifikasi menampilkan Mac dan proyek chat (`Studio Mac · recipe-box`), judul chat, dan teksnya: Turn finished menampilkan balasan terakhir agen. Dengan kunci APNs, teks ini melewati layanan push Apple. Tether tidak menyembunyikan pratinjau notifikasi di Layar Terkunci iPhone: matikan pratinjau itu di Pengaturan iOS. Titik hijau di Tether mengikuti Mac: chat yang Anda buka di dsh juga kehilangan titiknya di ponsel. Chat yang Anda buka di Tether juga kehilangan titiknya di dsh, dalam sekitar 3 detik selama jendela dsh terbuka, sehingga ponsel dan dsh menunjukkan jumlah yang sama. Untuk ini, jendela dsh mengubah daftar belum dibaca milik dsh melalui bagian dsh yang sama dengan **Tandai semua sudah dibaca** (bukan API publik). Chat yang diarsipkan tidak punya titik di ponsel, sama seperti di dsh. Mac yang Composer Plus-nya tidak punya daftar ini (versi lama) tidak menampilkan titik hijau di Tether.
- **Komputer jarak jauh** memerlukan Tailscale di kedua Mac, dan Composer Plus dengan fitur ini aktif di Mac yang Anda buka. Mac itu tidak boleh dalam mode tidur, dan dsh harus berjalan di sana. Pemilih hanya tampil saat bilah samping kiri terbuka (tidak saat bilah itu hanya menampilkan ikon). Jika halaman Mac lain tidak punya pemilih sendiri (Composer Plus di sana lebih lama dari 1.23.0), pemilih Mac ini muncul di atas halaman itu di tempat yang sama. Jika di sana ada 1.23.0 atau yang lebih baru, halaman Mac itu menampilkan pemilih dari versi Composer Plus miliknya sendiri (versi yang lebih lama menampilkan satu tombol, bukan dua bagian). Setiap komputer yang Anda buka menyimpan halamannya di memori sampai Anda menonaktifkan fitur ini atau memulai ulang dsh. Jika komputer itu tidak menjawab (sedang tidur atau Tailscale mati), halamannya tidak disimpan: pilih lagi, lalu halaman dimuat ulang. Di aplikasi desktop, halaman Mac lain adalah halaman tersemat: pintasan keyboard dsh sendiri (misalnya obrolan baru) tidak berfungsi di dalamnya, dan unduhan file, mikrofon, serta notifikasi juga tidak berfungsi di sana. Di macOS, halaman itu memenuhi seluruh jendela dan menggambar baris bilah judulnya sendiri, seperti halaman Mac ini; untuk memindahkan jendela, seret area di samping tombol lampu lalu lintas. Fitur ini memakai port 19392 (hanya satu dsh di setiap Mac yang dapat mengizinkan komputer lain masuk). Dari halaman Mac lain, pemilih hanya beralih di antara komputer Mac ini: Anda tidak dapat membuka Mac ketiga melalui Mac lain. Kedua bagian hanya menghitung komputer yang sudah dipasangkan dan dapat dijangkau (komputer yang harus dipasangkan lagi tidak dihitung); jika hanya ada satu komputer seperti itu, **Tambahkan komputer…** ada di menu klik kanan (di layar sentuh: tekan lama) atau di **Pengaturan → Composer Plus → Komputer jarak jauh**.
- Tautan sesi berfungsi di dalam obrolan; mengkliknya tidak membuka obrolan. - **Asisten** punya satu obrolan untuk semua jendela di Mac ini. Asisten berjalan dengan mode izin workspace-write: asisten hanya menulis file di `~/Assistant`, dan perintah di luar folder itu bertanya dulu. Jika Anda mengalihkan obrolan ke mode tanpa persetujuan (Akses penuh), dsh menolak setiap persetujuan, sehingga asisten tidak dapat mengirim pesan ke obrolan, memulai, menghentikan, atau mengarsipkan obrolan. Kartu persetujuan hanya menjaga enam alat itu: perintah shell dari asisten tetap dapat menjangkau jaringan, seperti di obrolan mana pun dengan mode itu. Di dsh 0.2.0 dan 0.2.1, alat jadwal dsh hanya melihat pengingat milik obrolan asisten itu sendiri, bukan otomatisasi obrolan lain; mulai dsh 0.2.2, alat itu menampilkan dan mengubah setiap tugas terjadwal. chats_list tidak menyertakan obrolan yang diarsipkan, obrolan kosong, obrolan subagen, dan obrolan asisten itu sendiri; “menunggu Anda” berarti ada persetujuan, pertanyaan, atau tinjauan rencana yang terbuka di obrolan yang berjalan. chat_read memberikan pesan pengguna dan balasan agen (tanpa output alat), paling banyak 50 pesan dan sekitar 24.000 karakter. chat_archive menolak obrolan yang masih berjalan atau masih punya pengingat aktif. Model tetap bisa tertipu oleh teks yang dibacanya: kartu persetujuan adalah pemeriksaan terakhir, jadi bacalah kartu itu sebelum Anda mengklik **Izinkan sekali**. Topik paralel memakai alat subagen dsh: profil atau mode izin tanpa alat itu tetap memakai cara lama (satu topik dalam satu waktu, pesan berikutnya menunggu di antrean atau mengarahkan giliran yang berjalan). Model yang menentukan apa yang dihitung sebagai tugas panjang, jadi pertanyaan singkat tetap bisa memakan satu giliran. Subagen setiap topik berjalan dengan tokennya sendiri; saat dsh dimulai ulang, topik yang berjalan berhenti (hasilnya tidak kembali). Hasil kembali sebagai giliran baru di obrolan asisten, jadi hasil itu menunggu saat Anda mengetik di tengah giliran.

Saat kartu persetujuan menunggu Anda, obrolan asisten tetap dihitung sibuk. Jika permintaan terbarunya tidak punya alat subagen (mode izin atau profil tanpa alat itu), aturan ini tidak melakukan apa pun. Dengan **Asisten selalu bebas**, pesan yang Anda kirim saat asisten bekerja masuk ke gilirannya pada langkah berikutnya, jadi antrean di bawah kolom input hanya menampilkannya sebentar; saat kartu pertanyaan menunggu, teks yang sama menjawab setiap pertanyaan di kartu itu. Perbaikan mengambil salinan dari cadangan: pesan setelah cadangan itu hilang dari obrolan tersebut (file yang rusak tetap ada di sebelahnya). Obrolan yang terbuka di dsh ini tidak diperbaiki di Pengaturan: dsh sedang memegangnya.
- **Pencadangan otomatis** hanya berjalan selama dsh berjalan: pencadangan yang jatuh tempo saat dsh ditutup berjalan sekitar 45 detik setelah dsh dimulai berikutnya. Snapshot untuk versi baru diambil setelah dsh dimulai itu, bukan sebelum pembaruan.
- **Ingat ukuran jendela** hanya berfungsi di aplikasi desktop. Setiap kali dimulai, dsh lebih dulu menampilkan jendelanya pada 1280 × 820; jendela berpindah ke ukuran yang disimpan saat plugin dimuat. Halaman tidak punya event untuk perpindahan jendela, jadi plugin membaca jendela sekali per detik: perubahan dalam 2 detik terakhir sebelum dsh ditutup tidak disimpan. Ukuran disimpan per komputer, di penyimpanan aplikasi itu sendiri.
- **Penghitungan penggunaan:** menghitung salinan, bukan orang: setiap dsh home adalah satu salinan. Hitungan salinan unik (`installed.txt`) hanya mencakup salinan yang diperbarui ke versi pertama yang punya file ini atau ke versi yang lebih baru; salinan yang tetap di versi lebih lama tidak dihitung. Salinan yang folder `storages`-nya dihapus akan dihitung lagi. GitHub dapat menghitung permintaan dari alamat IP yang sama (misalnya beberapa komputer di belakang satu router NAT) dalam sekitar 10 menit sebagai satu permintaan.
- Dukungan bawaan sudah diminta ke upstream: `move` antrean di [#773](https://github.com/deepseek-ai/deepseek-harness/discussions/773), status Lanjutkan di [#9269](https://github.com/deepseek-ai/deepseek-harness/discussions/9269).

## Pertanyaan umum

**Bagaimana cara menambahkan panel Perubahan / diff git ke DeepSeek Harness?** Pasang `dsh-composer-plus`, lalu bilah samping kanan → `+` → **Perubahan**.

**Bisakah dsh menyarankan fitur untuk proyek saya, seperti menggeser kartu Tinder?** Bisa: bilah samping kanan → `+` → **Ide fitur** → **Sarankan fitur**. Geser ke kanan untuk memulai obrolan baru yang merencanakan fitur itu, klik **▶ Buat sekarang** untuk memulai obrolan yang langsung membuatnya tanpa rencana, geser ke kiri untuk melewatinya.

**Bisakah pencarian bilah samping dsh menemukan obrolan dari kata di dalam pesannya, bukan hanya dari judulnya?** Bisa, dengan **Pencarian isi** (aktif secara default): mulai ulang dsh sekali setelah Anda memasang plugin, lalu gunakan kaca pembesar di samping **Ruang kerja**. Obrolan yang cocok menampilkan teks di sekitar kata itu.

**Bisakah saya membatalkan sebuah giliran dan mengedit prompt saya, seperti di OpenCode atau Claude Code?** Bisa, dengan **Putar balik giliran**: klik **↶** pada pesan, pilih **Obrolan dan file**, edit teks yang kembali ke kotak pesan, lalu kirim.

**Bisakah saya menghapus obrolan alih-alih mengarsipkannya?** Bisa, dengan **Hapus obrolan**: **…** → **Hapus…**. Riwayatnya masuk ke Tong Sampah, jadi kesalahan masih dapat dibatalkan.

**Bagaimana cara melihat sebuah obrolan termasuk ke proyek mana?** Lihat baris di bawah kotak pesan: dengan **Nama proyek di kotak pesan** (aktif secara default), baris itu dimulai dengan nama proyek. Arahkan penunjuk ke nama itu untuk melihat jalur folder.

**Bagaimana cara mendapatkan riwayat pesan ↑/↓ di kotak pesan dsh?** Pasang plugin ini; di kotak pesan yang kosong, `↑` / `↓` menelusuri pesan yang telah Anda kirim.

**Bagaimana cara melanjutkan giliran dsh yang dihentikan atau gagal tanpa mengetik "continue"?** Dengan plugin ini, tombol Kirim berubah menjadi **▶** setelah giliran dihentikan, gagal, atau terpotong; satu klik melanjutkannya.

**Apakah dsh melanjutkan obrolan yang sedang berjalan setelah saya keluar lalu membukanya lagi?** Tidak dengan sendirinya: dsh menandai giliran seperti itu sebagai terinterupsi dan menunggu (tujuan juga menunggu `/goal resume`). Aktifkan **Pengaturan → Composer Plus → Lanjutkan setelah mulai ulang**: obrolan yang sedang bekerja saat dsh ditutup akan berlanjut sendiri saat dsh dimulai berikutnya.

**Model mana yang menulis prediksi?** Model yang Anda pilih di **Pengaturan → Composer Plus → Prediksi pesan berikutnya → Model**. Daftarnya adalah daftar model milik dsh sendiri. **Default dsh** mengikuti model default dsh. Jika dsh tidak lagi menampilkan model yang dipilih, prediksi memakai model default. **Lengkapi saat mengetik** memiliki menu **Model** sendiri: **Sama dengan prediksi pesan berikutnya** (default) mengikuti model prediksi; pilihan lain hanya dipakai untuk pelengkapan. Jika dsh tidak lagi menampilkan model itu, pelengkapan memakai model prediksi.

**Bisakah dsh menyempurnakan prompt saya sebelum saya mengirimnya, seperti tombol Enhance prompt di Roo Code atau Augment?** Bisa, dengan **Sempurnakan prompt** (aktif secara default): ketik permintaan kasar, lalu klik tongkat ajaib di samping menu model. Fitur ini menulis ulang teks dengan obrolan ini dan proyek sebagai konteks, dalam bahasa Anda, dan tidak mengirimnya. `Cmd/Ctrl+Z` atau **Urungkan penyempurnaan** mengembalikan teks Anda. Pilih modelnya di **Pengaturan → Composer Plus → Sempurnakan prompt → Model**.

**Bisakah agen berhenti menandai pekerjaannya sendiri sebagai selesai, seperti loop pemeriksa dalam loop engineering?** Bisa, dengan **Pemeriksaan tujuan** (aktif secara default): mulai tujuan dengan `/goal`. Saat agen mengatakan tujuan sudah selesai, pengujian proyek dijalankan dan satu panggilan model independen memeriksa tujuan terhadap obrolan; jika salah satunya gagal, tujuan tetap terbuka dan agen membaca alasannya. Atur perintah pengujian Anda sendiri, batas waktu, atau batas token dengan **Edit** di baris **Pemeriksaan tujuan** di bawah tujuan.

**Bisakah agen mengingat preferensi saya antar-obrolan, seperti memori DS Bot?** Bisa, dengan **Memori proyek** (nonaktif secara default): aktifkan di **Pengaturan → Composer Plus**. Setelah setiap giliran, preferensi dan keputusan Anda yang bertahan lama disimpan sebagai catatan singkat untuk proyek obrolan itu, dan setiap obrolan baru di proyek itu membacanya. Minta agen mengingat sesuatu, dan agen langsung menyimpannya. Untuk melihat atau mengubah catatan, klik **Buka memori** di baris yang sama dan tulis apa yang diubah.

**Saya atau AI membuat perubahan yang salah pada memori. Bisakah saya mendapatkan catatan lama kembali?** Bisa, dengan **Riwayat versi memori** (aktif secara default): di **Buka memori**, pilih proyek, lalu **Riwayat**. Pilih versi sebelum perubahan untuk melihat apa yang kembali, lalu **Pulihkan**.

**Bisakah saya membagikan memori proyek dengan tim atau alat agen lain?** Bisa, dengan **Ekspor memori ke AGENTS.md** (aktif secara default): di **Buka memori**, pilih proyek, lalu **Ekspor ke AGENTS.md**. Periksa diff, lalu **Tulis AGENTS.md**, dan commit file itu.

**Bisakah AI menyarankan apa yang disimpan dari chat yang panjang?** Bisa, dengan **Sarankan catatan memori dari chat** (aktif secara default selama **Memori proyek** aktif): klik **Sarankan untuk memori** di kepala chat, lalu **Terima** catatan yang layak disimpan.

**Bisakah saya melihat semua obrolan saya sebagai papan kanban dan memulai obrolan baru dari sana?** Bisa, dengan **Papan tugas** (aktif secara default): buka di bilah samping kiri. Setiap obrolan adalah kartu di **Sedang dikerjakan**, **Ditinjau** (obrolan menunggu Anda), atau **Selesai**. **Tugas baru** membuka obrolan baru dsh di proyek, dan papan kembali saat pesan pertama Anda terkirim; klik **Jawab** di kartu oranye untuk menjawabnya tanpa membuka obrolan. **Bersihkan semua** di **Selesai** bertanya dulu dan mengeluarkan kartu selesai yang sudah Anda baca dari papan; **Urungkan** dan **Dikeluarkan (N)** mengembalikannya, dan obrolannya tetap ada di dsh.

**Bisakah saya punya obrolan asisten pribadi yang mengingatkan saya dan mengelola obrolan saya yang lain?** Bisa, dengan **Asisten** (aktif secara default): klik **Asisten** di bilah samping kiri. Asisten membuat pengingat dengan tugas terjadwal dsh, mencari di web, menampilkan daftar dan membaca obrolan Anda, serta mengirim pesan ke obrolan atau memulai, menghentikan, atau mengarsipkan obrolan hanya setelah Anda menyetujuinya. Simpan profil Anda di memori proyeknya, topik “profil”.

**Bisakah asisten tidak muncul di daftar obrolan saya dan bekerja seperti bot?** Bisa. **Asisten terpisah dari obrolan** mengeluarkan obrolannya dari daftar bilah samping dan menampilkan statusnya di baris **Asisten** (oranye saat menunggu Anda). **Hanya pesan di Asisten** menyembunyikan langkah kerjanya. **Asisten selalu bebas** membuat asisten menyerahkan setiap langkah yang lebih lama ke subagen latar belakang, jadi asisten langsung menjawab. **Kabar obrolan dari Asisten** (nonaktif secara default, memakai token) membuat asisten memberi tahu Anda saat obrolan lain selesai, gagal, atau menunggu Anda. Secara default (**Hanya otomatisasi**), asisten hanya memberi tahu tentang giliran yang dimulai oleh tugas terjadwal (juga di obrolan yang Anda mulai), setelah setiap giliran itu, seperti subagen melapor; pilih **Semua obrolan** di **Beri tahu tentang** untuk mendengar tentang semua obrolan.

**Bisakah dsh mencadangkan obrolan dan pengaturan saya, seperti dsh-backup?** Bisa: **Pengaturan → Composer Plus → Pencadangan → Cadangkan sekarang**. Fitur ini menulis format arsip yang sama ke folder yang sama (`~/Desktop/dsh-backups`), jadi arsip dsh-backup juga tampil dan dapat dipulihkan, dan Anda dapat menghapus dsh-backup. Aktifkan **Pencadangan otomatis** untuk pencadangan terjadwal.

**dsh tidak mau dimulai lagi. Bagaimana cara memulihkan cadangan?** Buka folder cadangan (`~/Desktop/dsh-backups`) dan klik dua kali `Composer Plus Rescue.command` (Linux: `composer-plus-rescue.sh`, Windows: `Composer Plus Rescue.cmd`). Pilih `3) Restore a backup`, pilih satu cadangan, lalu ketik `RESTORE`. Cara ini berjalan tanpa dsh.

**Bagaimana cara memindahkan dsh ke komputer baru?** Di komputer lama: **Pencadangan** → **Untuk komputer lain** di sebelah sebuah cadangan. Salin folder itu ke komputer baru, pasang dsh di sana, keluar dari dsh, buka `Composer Plus Rescue` di folder salinan, lalu pulihkan. Masukkan lagi kunci API Anda (kunci itu tetap ada di komputer lama).

**Sebuah obrolan tidak bisa dibuka setelah crash. Bisakah saya memperbaikinya?** **Pengaturan → Composer Plus → Pemeriksaan log sesi → Periksa log sesi**. Obrolan yang rusak kembali dari cadangan terbaru dengan **Perbaiki dari cadangan** (pesan setelah cadangan itu hilang).

**Bagaimana cara mengubah urutan pesan dalam antrean di dsh?** Seret pegangan ⠿ pada pesan dalam antrean, atau fokuskan pegangan itu lalu tekan `↑` / `↓`.

**Bagaimana cara memperbaiki salah ketik di pesan dalam antrean?** Klik dua kali pesan di antrean, ubah teksnya, lalu tekan `Enter` (`Esc` membatalkan). Pesan tetap di tempatnya dalam antrean. Di sana Anda juga dapat menghapus gambar dan file-nya, atau menambahkan yang baru.

**Bagaimana cara menghapus semua titik belum dibaca di satu proyek sekaligus?** Bilah samping → tombol **…** proyek → **Tandai semua sudah dibaca**.

**Bisakah saya menautkan ke satu pesan di obrolan yang panjang?** Bisa: arahkan penunjuk ke pesan itu dan klik **🔗**. Kirim tautan itu di obrolan: di dsh 0.2.1 dan yang lebih baru, klik pada tautan membuka obrolan di pesan itu.

**Saya tidak sengaja memutar balik giliran. Bisakah saya mendapatkannya kembali?** Bisa, dengan **Ulangi** di atas kotak pesan, tepat setelah putar balik: fitur ini memulai obrolan baru dari tepat sebelum putar balik dengan pesan yang sama, dan jika putar baliknya memakai **Obrolan dan file**, file juga dikembalikan.

**Obrolan mana yang mengubah file ini?** Bilah samping kanan → **Perubahan** → **…** milik file → **Obrolan yang mengubah file ini**. Klik sebuah baris untuk membuka obrolan itu di permintaan yang membuat perubahan.

**Bisakah saya mencari di dalam satu obrolan yang panjang?** Bisa: tekan `Cmd+F` di Mac (`Ctrl+F` di Windows dan Linux) di obrolan. **Cari di obrolan** menyorot setiap kecocokan dan berpindah di antaranya dengan `Enter` dan `Shift+Enter`.

**Bagaimana cara melihat hanya file yang diubah oleh satu obrolan?** Bilah samping kanan → **Perubahan** → **Obrolan ini**. Klik **␣** untuk menyembunyikan perubahan yang hanya berupa spasi.

**Bagaimana cara menghentikan agen agar tidak menjalankan `npm publish` atau `git push --force`?** **Pengaturan → Composer Plus → Perintah yang diblokir**: ketik `npm publish`, pilih **blokir** atau **tanya dulu**, lalu klik **Tambah**. **blokir** menolak perintah itu dan agen bertanya kepada Anda; **tanya dulu** menampilkan kartu persetujuan setiap kali. File yang dilindungi mencakup alat file agen; Perintah yang diblokir mencakup perintah shell-nya.

**Bisakah saya memberi tahu agen mengapa saya menolak panggilan alat?** Bisa, dengan **Tolak dengan catatan** (aktif secara default): klik **Tolak dengan catatan…** pada kartu persetujuan, tulis alasannya atau apa yang harus dilakukan sebagai gantinya, lalu klik **Tolak**. Agen membaca penolakan dan catatan Anda di giliran yang sama.

**Bagaimana memberi agen kata sandi atau token tanpa menulisnya di obrolan?** Dengan **Input rahasia** (aktif secara default): minta agen memakai `request_secret`, atau tunggu sampai agen memintanya. Ketik nilai di kartu pada baris alat dan klik **Simpan**. Agen hanya menerima path file yang berisi nilai, dan file dihapus saat giliran berakhir.

**Bagaimana membalas hanya satu bagian dari jawaban yang panjang?** Pilih bagian itu dan klik **Kutip** di atas pilihan (**Kutip dalam balasan**, aktif secara default). Bagian itu masuk ke kolom ketik sebagai kutipan `> …`, dan Anda menulis balasan di bawahnya.

**Bagaimana menunjukkan baris yang tepat dari sebuah file kepada agen?** Buka file di bilah samping kanan (**File ruang kerja**), pilih baris-barisnya, lalu klik **Kutip** di atas pilihan (**Kutip dari pratinjau file**, aktif secara default). Kolom ketik menerima path dan nomor baris (misalnya `src/login.js:2-3`) serta baris-baris itu sebagai blok kode; tulis pertanyaan Anda di bawahnya.

**Bisakah saya bertanya saat agen bekerja, tanpa menghentikannya?** Ketik pertanyaan dan klik **Tanya di obrolan samping** di kolom ketik (**Obrolan samping**, aktif secara bawaan). Salinan obrolan yang hanya baca menjawabnya sementara obrolan terus bekerja. Di obrolan samping, **Bawa kembali** menaruh jawaban di kolom ketik obrolan.

**Bagaimana memberi tahu agen apa yang harus diubah di diff-nya?** Di **Panel perubahan**, buka diff file, klik **+** pada sebuah baris, dan tulis catatan (**Catatan diff**, aktif secara bawaan). Lalu klik **Kirim ke kolom ketik**: catatan masuk ke kolom ketik bersama file, nomor baris, dan barisnya.

**Bagaimana cara menghentikan Tinjauan otomatis agar tidak terus bertanya tentang alat yang sama dalam satu obrolan?** Klik **Izinkan untuk obrolan ini** pada kartu persetujuan. Izin ini hanya mencakup alat itu di obrolan itu, selama 1 jam secara default; cabut izin dari chip di header. Ubah waktunya di **Pengaturan → Composer Plus → Izinkan untuk obrolan ini**.

**iPhone saya hilang. Bagaimana cara mencegahnya mengakses Mac saya?** Klik **Koneksi seluler** di kiri bawah bilah samping, lalu klik **Remove** di samping iPhone itu. Kuncinya langsung tidak berfungsi; iPhone itu hanya dapat kembali dengan pemasangan baru yang Anda setujui di Mac.

**Bagaimana cara melanjutkan obrolan dari Mac saya yang lain di Mac ini?** Di Mac yang lain, aktifkan **Pengaturan → Composer Plus → Komputer jarak jauh** dan **Izinkan komputer lain membuka Mac ini**, klik **Buat tautan pemasangan**, lalu salin tautannya (kirim ke diri Anda sendiri, misalnya dengan AirDrop atau Catatan). Di Mac ini, aktifkan juga **Komputer jarak jauh**, pilih **Tambahkan komputer…** di pemilih pada bilah samping kiri (di bawah nama merek, di atas **Sesi Baru**), tempel tautannya, ketik **Nama**, lalu klik **Hubungkan**. Setelah itu, klik **Setujui** di Mac yang lain. Sejak saat itu, klik nama komputer tersebut di pemilih: komputer itu memenuhi jendela ini. Klik **Mac ini** di tempat yang sama untuk kembali. Sementara itu, obrolan di Mac ini tetap berjalan.

**Bisakah saya mengunci Tether dengan Face ID?** Bisa: di Tether, aktifkan "Settings → Privacy → Lock with Face ID". Setelah itu, Tether meminta Face ID (atau kode sandi) saat dibuka dan saat Anda kembali ke aplikasi itu.

**Bagaimana cara hanya menampilkan proyek yang saya pakai hari ini di bilah samping dsh?** Bilah samping → opsi tampilan (ikon slider) → **Aktif dalam 2 jam terakhir**. Pilih lagi untuk menampilkan semua proyek.

**Bagaimana cara menyalin jalur folder proyek di dsh?** Klik kanan proyek di bilah samping → **Salin jalur**.

**Bagaimana cara menciutkan semua proyek di bilah samping dsh sekaligus?** Klik tombol ciutkan di samping opsi tampilan (ikon slider). Tombol ini muncul selama ada setidaknya satu proyek yang terbuka.

**Bagaimana cara mendapatkan notifikasi macOS / Windows saat tugas dsh selesai atau memerlukan persetujuan?** Biarkan **Notifikasi latar belakang** aktif (default) dan izinkan notifikasi untuk DeepSeek Harness di pengaturan OS.

**Bisakah dsh membuka sendiri obrolan yang mengajukan pertanyaan kepada saya?** Ya, dengan **Buka obrolan yang menunggu saat tidak aktif** (aktif secara default): saat obrolan menunggu jawaban, persetujuan, atau tinjauan rencana dan Anda tidak menggunakan dsh selama 30 detik, dsh membukanya. Obrolan yang menyelesaikan giliran yang belum Anda baca (titik hijau) dibuka dengan cara yang sama, setelah obrolan oranye. Selama Anda mengetik, menggulir, atau menggerakkan mouse, fitur ini menunggu.

**Bisakah saya langsung pindah ke obrolan berikutnya yang menunggu saya?** Bisa, dengan **Obrolan menunggu berikutnya** (aktif secara default): tekan `Cmd+Shift+E` (`Ctrl+Shift+E` di Windows dan Linux) atau klik tombol berangka di kepala bilah samping. Obrolan yang mengajukan pertanyaan atau menunggu persetujuan didahulukan, lalu obrolan yang menyelesaikan giliran yang belum Anda baca.

**Bisakah saya menjawab opsi dari agen dengan satu klik?** Bisa, dengan **Tombol opsi** (aktif secara default): saat jawaban diakhiri daftar "Opsi", klik salah satu tombol di bawahnya. Tombol itu mengirim "Option N: …" sebagai pesan Anda. Pada kartu pertanyaan agen, tekan 1–9.

**Bisakah saya mengirim kalimat persetujuan agen tanpa mengetiknya?** Bisa, dengan **Tombol Setujui** (aktif secara default): saat agen memerlukan persetujuan tertulis, agen menulis kalimat itu dalam blok `onay`. Klik **Setujui** di bawah jawaban: kalimat itu dikirim apa adanya sebagai pesan Anda, sehingga Tinjauan otomatis melihatnya dari Anda. Kalimat yang menyebut target langsung atau publik tidak punya tombol: ketik sendiri.

**Bagaimana cara mengganti antarmuka DeepSeek Harness ke bahasa Turki, Spanyol, Jepang…?** Pengaturan → Composer Plus → **Bahasa aplikasi**.

**Bagaimana cara memakai dsh dari iPhone saya?** Bangun aplikasi Tether dari `tether/ios` (Xcode), aktifkan **Pengaturan → Composer Plus → Koneksi seluler (iPhone)**, klik **Koneksi seluler** di kiri bawah, pindai kode QR (Kamera iPhone atau **Scan code** di Tether), ketuk **Connect**, lalu klik **Approve**. Saat jauh dari rumah, gunakan Tailscale di kedua perangkat.

**Bagaimana agar Sesi Baru selalu terbuka di proyek yang sama?** Pengaturan → Composer Plus → **Ruang kerja default untuk Sesi Baru** → **Buka Sesi Baru di** → pilih proyeknya. `+` di samping proyek lain tetap membuka proyek itu.

**Bagaimana cara mengerjakan beberapa fitur dari satu proyek sekaligus, masing-masing di branch-nya sendiri?** Dengan **Branch per obrolan**: di layar obrolan baru, tombol branch menampilkan **Branch baru** secara default: kirim pesan pertama. Setiap obrolan mendapat branch dan folder worktree sendiri, beserta `.env` dan `node_modules` Anda jika `.worktreeinclude` mencantumkannya. Header obrolan menampilkan branch tempat Anda berada.

**Bisakah bilah samping menampilkan setiap branch sebuah proyek dan memindahkan obrolan saya saat agen membuat branch?** Bisa, dengan **Branch di pohon ruang kerja** (mati secara default): nyalakan di Pengaturan → Composer Plus, lalu pilih **Opsi tampilan** → **Pohon Ruang Kerja** di dsh. Setiap branch yang punya worktree di `<project>/.worktrees/` tampil di dalam proyeknya. Saat Anda meminta agen di folder proyek membuat branch dan bekerja di sana, dan folder tidak punya perubahan yang belum di-commit, obrolan pindah sendiri ke branch itu. Hapus folder branch dan branch keluar dari daftar; obrolannya pindah ke **Tanpa grup**.

**Bisakah saya mengirim foto dari iPhone?** Bisa. Di obrolan Tether, ketuk **+** di samping kolom pesan → Camera, Photos (hingga 4) atau Paste image. Foto dikirim ke obrolan di Mac sebagai lampiran pesan Anda, jadi model dapat melihatnya.

**Bisakah dsh menjalankan perintah berikutnya tanpa bertanya lagi ke model?** Bisa, dengan **Langkah terencana** (nonaktif secara default): aktifkan di Pengaturan → Composer Plus. Model lalu dapat merencanakan perintah berikutnya dengan sebuah syarat, misalnya “jalankan tes jika build berhasil”, dan Composer Plus menjalankan langkah tanpa panggilan model baru ketika hasilnya memenuhi syarat. Persetujuan dan sandbox tetap seperti biasa.

Composer Plus memasangnya hanya saat **Bahasa aplikasi** adalah Türkçe, hanya menyimpan file Markdown-nya, dan tidak menjalankan skripnya. Untuk menghapusnya, matikan **Paket skill bahasa Turki** di Pengaturan → Composer Plus: skill dan salinan yang diunduh langsung terhapus.

**Bagaimana cara melaporkan bug atau meminta fitur di Composer Plus?** Pengaturan → Composer Plus → **Laporkan isu…** (atau menu **…** obrolan → **Laporkan isu Composer Plus…**). Pilih jenis, jelaskan dalam bahasa Anda sendiri, lalu klik **Tulis draf**. Periksa draf berbahasa Inggris, lalu klik **Buka isu**.

**Bagaimana agen merapikan basis kode yang berantakan?** Ketik `/untangle-codebase` di obrolan (**Rapikan basis kode**, aktif secara default), bila perlu dengan suatu bagian, misalnya `/untangle-codebase src/api`. Agen pertama-tama mendaftar salinan, keterkaitan tersembunyi, pembungkus yang tidak perlu, kode mati, dan kasus khusus, lalu memperbaikinya sebagai tujuan dan memeriksa lagi dengan subagen. Mulai skill ini di obrolan **Branch per obrolan** agar pekerjaannya tetap di branch sendiri.

**Apakah plugin ini berfungsi di aplikasi desktop?** Ya: Pengaturan → Plugin → **Tambahkan plugin** → `dsh-composer-plus`. Diuji pada dsh 0.2.0-rc.2 (desktop dan web) dan 0.2.1-rc.2 (web).

**Aturan untuk fitur baru:** setiap baris fitur di Pengaturan → Composer Plus menampilkan tangkapan layar. Tambahkan id fitur ke `SHOT_OF` di `client.js` dan ke `SHOTS` di `index.js`, lalu sertakan `assets/features/<id>.webp` (diambil dari dsh demo sekali pakai, UI bahasa Inggris, sekitar 60 kB atau kurang). Tambahkan fitur itu, dengan gambar yang sama, ke `docs/features.json` lalu jalankan `npm run build:readme`: perintah ini menulis tabel fitur di `README.md` dan di setiap `README.<id>.md` terjemahan, serta daftar di `llms.txt`. `test/shots.test.mjs` gagal jika sebuah fitur tidak memiliki tangkapan layar, dan `test/browser-settings-shots.mjs` memeriksa halaman Pengaturan yang asli. Daftar periksa lengkap untuk setiap perubahan ada di [AGENTS.md](AGENTS.md).

Pengujian menjalankan `client.js` yang asli terhadap React/DOM palsu, dan `index.js` (bagian Host) yang asli terhadap repositori git sementara. Pengujian gateway Tether (`test/tether-gateway.test.mjs`) memakai host dsh tiruan dan gateway TLS sungguhan. Aplikasi iPhone ada di `tether/ios` (lihat [tether/README.md](tether/README.md) dan [tether/AGENTS.md](tether/AGENTS.md)). Setiap rute Host, permintaannya, dan apakah Tether dapat memanggilnya tercantum di [docs/ROUTES.md](docs/ROUTES.md). `node test/browser-history.mjs '<dsh web URL with ?token=…>'` memeriksa riwayat input di browser sungguhan terhadap `dsh web` sekali pakai dengan `DSH_HOME` miliknya sendiri.

Paket bahasa adalah JSON yang hanya berisi data di `locales/<id>.json`, yang disematkan ke dalam satu entri klien oleh `npm run build:locales` (tanpa layanan terjemahan atau unduhan saat runtime). `npm test` memeriksa setiap paket untuk cakupan kunci yang lengkap, placeholder dan jeda baris yang identik, serta perilaku sistem/override. Untuk pemeriksaan terisolasi di aplikasi sungguhan dengan Playwright yang terpasang secara lokal:

```sh
PLAYWRIGHT=/path/to/playwright node test/browser-language.mjs /path/to/dsh/lib/bin.js
```
